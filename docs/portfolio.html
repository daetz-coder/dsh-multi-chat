项目亮点的技术深度

🪟 多窗口墙（Multi-Window Wall）

在官方 Web 界面内并排显示 N 个 DSH Agent 实例（一个端口一格），通过 conversation.view / sidebar.footer.action 增量列表槽位注册，不改写任何官方核心逻辑。

官方 bundle 形态Cordis 插件

🔍 Port 自动发现

扫描端口区间自动发现运行中的实例（自动排除自身端口），经只读 JSON 路由 /multi/api/ports / status / create / stop / link 探活与生命周期管理。

只读路由零侵入

🔐 认证局域网网关

为解决 DSH 禁止 --host 0.0.0.0 的远程安全限制，内置带 HMAC 签名会话 Cookie 的反向代理网关（node:net），支持手机/平板远程访问。

安全设计node:net

🐚 跨平台 CLI + 官方形态

提供 npx dsh-multi-chat install|start|stop|gateway，采用官方 dsh.bundle.patch 声明式 bundle 形态，实现「一行安装、一行卸载」，无需手动改 patch。
